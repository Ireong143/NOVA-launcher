SAND OS

SAND OS — 나만의 Android 기반 운영체제를 향한 프로젝트

SAND OS는 Kotlin과 Jetpack Compose를 기반으로 개발하는 독자적인 OS 프로젝트입니다.

현재는 Android 런처 형태의 초기 버전을 개발하고 있으며, 장기적으로 AOSP 기반의 독립적인 운영체제를 만드는 것을 목표로 합니다.

주요 기능

홈 화면

- 디지털 시계와 날짜
- 날씨 표시
- 검색 기능
- 즐겨찾기
- 여러 홈 화면 페이지
- 배경화면 변경

앱 서랍

- 설치된 앱 자동 표시
- 앱 검색 및 실행
- 앱 정렬
- 즐겨찾기 및 앱 관리

제어 센터

- Wi-Fi 및 블루투스 바로가기
- 화면 밝기와 볼륨
- 화면 회전
- 다크 모드
- 손전등 및 비행기 모드
- 배터리 정보

시스템 설정

- 테마 및 강조색
- 배경화면 설정
- 아이콘 및 글자 크기
- 애니메이션 설정
- 홈 화면 구성

추가 앱

- 계산기
- 메모
- 시계 및 타이머
- 앱 관리 및 앱 정보

개발 로드맵

1. 프로젝트 이름과 디자인을 SAND OS로 통일
2. 홈 화면 및 앱 서랍 개선
3. 잠금 화면과 알림 센터 개발
4. 자체 설정 및 제어 센터 개발
5. SAND OS 전용 시스템 UI 개발
6. AOSP 기반 실제 운영체제 개발
7. 지원 기기 테스트 및 설치

개발 환경

- 언어: Kotlin
- UI: Jetpack Compose
- 빌드: Gradle
- 자동 빌드: GitHub Actions

프로젝트 목표

단순한 런처를 넘어 독자적인 디자인과 기능을 갖춘 실제 운영체제 SAND OS를 만드는 것이 최종 목표입니다.
